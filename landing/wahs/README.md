# WA Health Summary (WAHS) Public Pages

- `https://openclinai.org/wahs/` (`landing/wahs/index.html`): Project overview, embedded live Web App (`shl-ips`) and Mobile Companion demo videos (hosted on `gs://openclinai-media/wahs/`), 5-stage pipeline summary, and November 26 blinded H200 benchmark headlines.
- `https://openclinai.org/wahs/architecture/` (`landing/wahs/architecture/index.html`): Technical architecture and builder reference: services and networks, the five-stage `wahs-engine` pipeline, request lifecycle, client integrations, FHIR star-graph data model, identity/state/caching layers, engine internals and citation namespaces, HTTP/SSE contract, enricher runtime, budgets and context allocation, SMART Health Links sharing, edge access control, runtime configuration (package vs hosted defaults), and local stack. No benchmark results or release history.
- `https://openclinai.org/wahs/llm-strategy/` (`landing/wahs/llm-strategy/index.html`): LLM strategy and design rationale: design constraints, two-region prompt structure and grounding rules, three-tier deterministic condensation, question-aware context enrichment, single-pass orchestration, Gemma 4 model selection, context sizing, privacy/provenance boundaries, factorial evaluation design, and current limitations. Empirical results live in the evaluation reports, not on this page.
- `https://openclinai.org/wahs/walkthrough/` (`landing/wahs/walkthrough/index.html`): Mobile app walkthrough for general and clinical readers. Follows the synthetic patient Margaret through the WAHS mobile companion step by step (sign in, home, records, personal notes, Ask WAHS with citations, missing information, sharing). Screenshots are hosted on `gs://openclinai-media/wahs/mobile-walkthrough-20261127/`.
- `https://openclinai.org/wahs/sandbox/` (`landing/wahs/sandbox/index.html`): Research Sandbox guide for the public tool at `wahs-demo.openclinai.org`: the three tabs, connecting a hosted or local model, three guided exercises (large records, optional context, citations and missing information), and a glossary of sandbox terms.

Developer and local-stack setup lives in the "Running WAHS locally" block of `/wahs/architecture/#env-config`, not on the walkthrough pages.

Retired `/wahs/engine-reference/*`, `/wahs/engine-audit/*`, and `/med-agent-hub/wahs-architecture/*` paths redirect permanently (`308`) to `/wahs/architecture/` via `compose/website/Caddyfile`; `/wahs/design-report/*` redirects (`308`) to `/wahs/llm-strategy/`.
