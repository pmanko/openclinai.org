# WA Health Summary (WAHS) Public Pages

- `https://openclinai.org/wahs/` (`landing/wahs/index.html`): Project overview, embedded live Web App (`shl-ips`) and Mobile Companion demo videos (hosted on `gs://openclinai-media/wahs/`), 5-stage pipeline summary, and November 26 blinded H200 benchmark headlines.
- `https://openclinai.org/wahs/architecture/` (`landing/wahs/architecture/index.html`): Layered architecture guide and builder reference covering the 5-stage pipeline (`FHIR Sources -> Zero-Privilege Auth -> Extract & Condense -> Profile/Prompt & Enrichers -> LLM & Provenance`), Margaret Chen worked trace, isolation/caching layers, OpenAI `/v1` + SSE wire contract, declarative `profiles.yaml`, 5 generalizable enrichers, 64k warm `num_ctx` rules, and runtime env config.
- `https://openclinai.org/wahs/llm-strategy/` (`landing/wahs/llm-strategy/index.html`): Plain-language team strategy and design rationale covering what we tried, kept, and retired, November 26 Run 3A & Run 3B evaluation findings, Gemma 4 model tiers, security/governance, and glossary.
- `https://openclinai.org/wahs/walkthrough/` (`landing/wahs/walkthrough/index.html`): Hands-on walkthrough across all three live surfaces (zero-logic Explorer Sandbox `wahs-demo.openclinai.org`, Web App `shl-ips`, and Mobile Companion) with reproducible budget, enricher, and citation/abstention experiments.
